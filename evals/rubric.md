# Insight quality rubric (draft: refine after reading real answers)

An insight or answer PASSES only if all five are true:

1. **Grounded:** every claim is supported by the reviews it cites.
2. **Numbers correct:** every number matches the database / tool results.
3. **Specific:** names a concrete thing to fix ("weekend dinner wait times over
   30 min", "biryani served cold on delivery"), not "improve service".
4. **Relevant:** answers the question for the right place and period.
5. **Honest about uncertainty:** flags low review counts instead of overstating.

For each FAIL, note which criterion failed; these feed the failure taxonomy.

Judge prompt tip: give the judge the question, the answer, the tool results, the
full text of cited reviews, and this rubric. Ask for a reason first, then
PASS/FAIL.
